# انتشار نسخه‌ی نمایشی با GitHub Pages

این ریپو دو سامانه‌ی استاتیک را از یک ریپو منتشر می‌کند:

- صفحه‌ی معرفی: ریشه‌ی سایت
- فروشگاه مشتریان: پوشه‌ی \`/storefront/\`
- پنل حسابداری امانی: پوشه‌ی \`/panel/\`

## فعال‌سازی یک‌باره
در تنظیمات مخزن به بخش **Settings → Pages** برو و در بخش **Build and deployment**، مقدار **Source** را روی **GitHub Actions** بگذار. سپس در **Actions** گردش‌کار **Publish GitHub Pages presentation** را اجرا کن؛ بعد از فعال‌سازی اولیه، تغییرات بعدی در فایل‌های مربوط به صورت خودکار منتشر می‌شوند.

## داده و امنیت در نسخه‌ی نمایشی
- نسخه‌ی Pages فقط برای دیدن ظاهر و نمایش مسیرهای اصلی است.
- پنل از داده‌های ساختگی و واضحاً نمایشی استفاده می‌کند و هیچ درخواست همگام‌سازی یا تغییر وضعیت روی سرور را از نسخه‌ی Pages نمی‌فرستد.
- سفارش واقعی، ورود امن چندکاربره، پرداخت و همگام‌سازی اطلاعات تا زمان استقرار API و تنظیمات امن فعال نیستند.
- هر محتوایی که با Pages منتشر می‌شود عمومی است؛ اطلاعات مشتری، رمز، توکن یا فایل \`.env\` را هرگز وارد خروجی Pages نکن.
