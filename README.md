# زیتون فدک 🫒
سامانهٔ فروشگاه اینترنتی و مدیریت حسابداری امانی فروشگاه‌ها.

## اجزای پروژه
- `apps/storefront/`: وب‌سایت مشتریان؛ طراحی اصلی در فایل‌های جداگانهٔ HTML/CSS/JavaScript.
- `apps/panel/`: پنل مدیریت امانی، فروش، فروشگاه‌ها و تطبیق تراکنش‌های کارت‌خوان.
- `backend/`: API مرکزی و ذخیره‌سازی دائمی اطلاعات.
- `docs/`: راهنمای نگهداری، به‌روزرسانی و استقرار.
- `scripts/`: ابزارهای پشتیبان‌گیری، بازیابی و انتشار نسخه.
- `.github/workflows/`: بررسی خودکار پایه برای جلوگیری از انتشار فایل‌های خراب.

## قانون مهم انتشار
تغییرات توسعه ابتدا در یک شاخهٔ جداگانه انجام می‌شوند. پیش از انتشار، آزمون‌ها و بررسی‌های خودکار اجرا می‌شوند؛ اطلاعات مشتریان و داده‌های پایگاه‌داده نباید داخل فایل‌های فرانت‌اند یا Git قرار بگیرند. تنظیمات محیطی فقط از `.env` خوانده می‌شوند.

## شروع سریع توسعه
1. فایل `.env.example` را به `.env` کپی کنید و رمزها را تنظیم کنید.
2. با Docker Compose سرویس‌ها را اجرا کنید.
3. راهنمای [راه‌اندازی](docs/DEPLOYMENT.md) و [به‌روزرسانی](docs/UPDATING.md) را بخوانید.

> درگاه پرداخت، پیامک و اتصال خودکار کارت‌خوان فیزیکی تا زمان دریافت و اعتبارسنجی اطلاعات رسمی ارائه‌دهنده، فعال فرض نمی‌شوند.
